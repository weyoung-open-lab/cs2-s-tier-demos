# CS2 S-Tier Demos (Parquet)

Professional *Counter-Strike 2* match demos from S-tier events (2023–2026), parsed to Parquet with awpy 2.0.2:
2,299 matches, about 134 GB. This repository mirrors the seven Kaggle datasets and adds the cleaned tables
used in the paper.

**Upload in progress.** The data files are being uploaded as GitHub Release assets. This page will list every
file, its checksum and a one-line download script when the upload is complete.
